# MovieFinder

MovieFinder is a React app that leverages the TMDB API to help users discover movies. Explore trending movies, search for specific titles, or filter by genres. Each movie includes detailed information to help you decide what to watch next.

## Features

- **Search & Filter**: Quickly find movies by title or filter by genres.  
- **Movie Details**: See cast, description, rating, runtime, release date, and similar movies.  
- **Watchlist**: Add movies to your personal watchlist to track what you want to watch.  
- **Rate Movies**: Rate movies in your watchlist to keep track of your favorites.
